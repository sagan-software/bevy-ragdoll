# Phase 2: the ragdoll profile

Goal: `RagdollProfile`, its validation, its RON asset loader, its builder,
the Skein authoring components, and reading TGF's rig GLB, all tested
without a physics engine.

Read first: [../architecture.md](../architecture.md) (Data model),
[../reference/tgf-port-map.md](../reference/tgf-port-map.md) (desc.rs,
ragdoll.rs, rig.rs), [../reference/algorithms.md](../reference/algorithms.md)
section 1.

## Steps

1. Copy `~/Code/gitlab.com/liamcurry/tgf/content/rigs/human/build/human.glb`
   to `assets/rigs/tgf_human/tgf_human.glb` and add its
   `assets/CREDITS.md` entry.
2. Write the failing integration tests in `crates/bevy_ragdoll/tests/profile.rs`
   (list below). Run `cargo test -p bevy_ragdoll --test profile` and keep
   the failure output in the commit body.
3. Create the modules, one primary type per file, each starting with a
   `//!` comment: `profile/mod.rs` (`RagdollProfile`, `BodyIndex`),
   `profile/spec.rs` (`ProfileSpec`, `BodySpec`, `JointSpec`,
   `ShapeSpec`), `profile/limits.rs` (`AngleRange`, `JointLimits`),
   `profile/error.rs` (`ProfileError`), `profile/builder.rs`
   (`ProfileBuilder`), `profile/loader.rs` (`RagdollProfileLoader`, RON,
   extension `ragdoll.ron`), `skein.rs` (`RagdollBody`, `RagdollJoint`,
   degrees), `gltf_rig.rs` (`ProfileSpec::from_glb(bytes)`, reading bones,
   rest transforms, `tgf_length` extras, capsule nodes and Skein extras),
   `geometry.rs` (`segment_distance`, private). Keep `lib.rs` a facade of
   private modules and re-exports.
4. Implement validation in the order of `ProfileError` in the
   architecture. Derive `no_contact` and `children` masks. Compute capsule
   endpoints in the body frame from each capsule node's local bounding box
   exactly as TGF's `Rig::body_in_bone` does.
5. Accept Skein extras under both `bevy_ragdoll::skein::RagdollBody` and
   `tgf_rig::ragdoll::RagdollBody` (and the same pair for joints).
6. Register reflected types and the asset loader in `RagdollPlugin`.
7. Add `assets/profiles/tgf_human.ragdoll.ron`, generated by a test helper
   from the GLB and committed, so the RON path has a real file.
8. Add internal `#[cfg(test)]` modules for private branches the public
   tests do not reach (segment distance degenerate cases, quaternion sign
   flip).

## Tests (`tests/profile.rs` unless noted)

- `tgf_human_has_sixteen_bodies_and_eighty_kilograms`: from the GLB; root
  is `pelvis`; total mass 80.0.
- `knees_are_hinges_that_bend_backward` and `hips_bend_forward` (port
  TGF `the_knee_bends_backwards_and_the_hip_forwards`).
- `each_error_variant_is_reported`: one spec per `ProfileError` variant,
  each changing exactly one field of a valid spec, asserting the exact
  variant. Also a spec with two problems asserts the earlier variant in
  validation order.
- `no_contact_holds_neighbours_and_touching_capsules`: joint pairs and the
  pairs closer than 0.01 m at rest are set; a far pair is clear.
- `ron_round_trip_is_exact`: spec to RON to spec equals.
- `ron_asset_loads_through_the_asset_server`: a headless `App` with
  `MinimalPlugins`, `AssetPlugin`, `RagdollPlugin` loads
  `profiles/tgf_human.ragdoll.ron` within 100 updates.
- `builder_matches_spec`: a 3-body chain from `ProfileBuilder` equals the
  hand-written spec.
- `skein_components_validate_like_tgf` (port TGF's `ragdoll.rs` tests).
- `old_skein_type_path_is_accepted`.
- `joint_angles_round_trip_each_axis` (algorithms.md section 1).

## Gates

The README gates, plus
`nix develop -c cargo llvm-cov -p bevy_ragdoll --summary-only`: every new
production file at 100 % line coverage, or a written reason per gap in the
commit body.

## Done when

- Every test above passes; the coverage gate holds.
- `cargo doc -p bevy_ragdoll --no-deps` builds with no warnings.
- `PLAN.md` marks phase 2 done.
